# WWE Title Universe

Simple local-first WWE 2K unlock and knockout-tournament companion.

## v0.1.0
- Home screen with WWE 2K15–2K26 console-game tiles (no 2K21).
- WWE 2K26 is the live test game.
- Roster, championship and arena MISSING/DONE tracking.
- Automatic tag-team readiness from member unlocks.
- Automatic tournament entrant counts.
- Local browser storage.
- Installable PWA shell / offline cache.

## Data status
WWE 2K26 is **provisional**. The current engine test imports the earlier 439-entry structured roster baseline. The next data pass reconciles it to TheSmackDownHotel as the preferred reference source.
